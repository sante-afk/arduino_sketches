### Arduino Projects Collection
This repository contains a collection of sketches for the Arduino 
platform demonstrating how to work with various sensors, actuators, 
and modules. Each sketch is a complete example for a specific component.

##### Content:
HC-SR04 (Ultrasonic Rangefinder)  
28BYJ-48 + E18-D80NK + Relay
DHT11 + LCD I2C (Temperature and Humidity)  
LED Control (Pin 9)  
LED Control with Delay (Pin 9)  
Basic LED Control (HIGH/LOW)  
RGB LED  
RFID-RC522 (Tag Reader)  
SG90 (Servo)
